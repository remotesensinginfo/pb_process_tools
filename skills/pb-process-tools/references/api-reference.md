# `pb_process_tools` API & CLI Reference (v4.0.2)

## Environment & Connection Configuration

PostgreSQL connection URL format (SQLAlchemy):

```text
postgresql+psycopg2://username:password@hostname:5432/database_name
```

Connection resolution order in `PBPTGenQProcessToolCmds` and `PBPTDatabaseCleaner`:
1. Direct `db_conn_str` argument
2. `db_conn_file` / `--dbfile` text file (newlines/whitespace stripped)
3. `PBPT_DB_CONN_STR` environment variable

Logging environment variables (`pbprocesstools/__init__.py`):
- `PBPT_LOG_LVL`: `INFO` (default), `DEBUG`, `WARNING`, `ERROR`, `CRITICAL`
- `PBPT_LOG_CFG`: path to JSON logging configuration file

## `pbprocesstools.pbpt_q_process`

### `PBPTQProcessTool` (Worker Base Class)

```python
PBPTQProcessTool(
    queue_db_info=None,   # Dict with "db_conn_str", "db_table_name", optional "db_schema"
    cmd_name=None,        # Script name for argparse prog
    descript=None,        # CLI description
    params=None,          # Optional single-job params dict
    uid_len=6,
    db_table_name=None,
    db_schema=None,
)
```

Abstract methods to implement:
- `do_processing(self, **kwargs)` — Execute processing using `self.params`. Raise an exception to mark the job errored (traceback captured into `ErrorInfo`).
- `required_fields(self, **kwargs) -> list[str]` — Return mandatory keys in `self.params`.
- `outputs_present(self, **kwargs) -> tuple[bool, dict]` — Return `(all_present, {filepath: error_msg})`. Typically calls `self.check_files(...)`.
- `remove_outputs(self, **kwargs)` — Delete outputs generated by `self.params`.

Execution entry point:
- `std_run(self, max_db_retries=5, **kwargs)` — Parses `--dbinfo`, `-j/--job`, `-p/--params`, `-r/--rmouts`; runs single-job debug mode when `-j` is given, or loops claiming pending jobs (`Started=False, Completed=False, Error=False`) atomically via `FOR UPDATE SKIP LOCKED` until queue is empty.

### `PBPTGenQProcessToolCmds` (Queue & Script Generator Base Class)

```python
PBPTGenQProcessToolCmds(
    cmd,                      # Worker invocation command, e.g. "python /abs/path/perform_analysis.py"
    sqlite_db_file=None,      # Unsupported in v4.x (must remain None)
    db_conn_file=None,        # File with SQLAlchemy PostgreSQL URL
    lock_file_path=None,      # Deprecated & ignored
    uid_len=6,
    process_tools_path=None,  # Directory containing process_tools_mod if not on sys.path
    process_tools_mod=None,   # Module name containing process_tools_cls
    process_tools_cls=None,   # Class name subclassing PBPTQProcessTool
    db_conn_str=None,         # Direct PostgreSQL URL
    db_table_name=None,       # REQUIRED non-empty queue table name
    db_schema=None,           # Optional PostgreSQL schema name (auto-created if missing)
)
```

Abstract & lifecycle methods:
- `gen_command_info(self, **kwargs)` — Populate `self.params` (list of JSON-serializable dicts).
- `run_gen_commands(self)` — Abstract entry point called by `--gen` / `--append`; typically calls `gen_command_info()`, `pop_params_db()`, and either `create_shell_exe()` or `create_slurm_sub_sh()`.
- `pop_params_db(self, batch_size=5000, append=None, deduplicate=None)` — Drops & recreates table (unless `append=True` or `--append`), or delegates to `append_params_db()`. Honors `self.dry_run`.
- `append_params_db(self, batch_size=5000, deduplicate=True) -> int` — Ensures schema/table exists and inserts only jobs whose canonical JSON SHA-256 digest is not already in the table.
- `check_job_outputs(self, out_err_pid_file=None, out_err_info_file=None, n_workers=1, **kwargs)` — Checks `Checked=False` jobs across `n_workers` threads. Updates `Checked=True` on success; marks `Error=True` on missing/corrupt outputs while preserving worker error tracebacks.
- `remove_job_outputs(self, all_jobs=False, error_jobs=False, pids=None, **kwargs)` — Runs worker `remove_outputs()` and resets matching rows to pending (`Started=False, Completed=False, Checked=False, Error=False, ErrorInfo=None`).
- `reset_jobs(self, all_jobs=False, error_jobs=False, pids=None) -> int` — Resets DB state to pending without deleting output files.
- `get_jobs_status(self) -> dict` — Returns `total`, `pending`, `running`, `completed`, `checked`, `errors`, `pct_complete`, `pct_checked`, `rate_per_hour`, `eta_seconds`, `eta_str`, `mean_secs`, `db_table_name`, `db_schema`.
- `print_jobs_status(self, watch=False, interval_secs=5.0)` — Prints live summary once or polls until `pending == 0 and running == 0`.
- `inspect_job(self, pid: int, print_output: bool = True) -> dict` — Inspects a single job row.
- `get_job_errors(self, limit: Optional[int] = None, print_output: bool = True) -> list[dict]` — Lists errored or started-incomplete jobs.
- `create_jobs_report(self, out_report_file=None)` — Writes full JSON statistics (`job_n`, `job_times` incl. quartiles, `status`, `xerrors`).
- `drop_params_db()` — Drops this task's queue table.
- `parse_cmds(self, argv=None)` — Standard CLI parser for `GenCmds` scripts.

Script generation methods:
- `create_shell_exe(self, run_script, cmds_sh_file, n_cores, db_info_file=None)` — Writes executable GNU Parallel wrapper (`#!/bin/bash`, `chmod 0o755`), `cmds_sh_file`, and `db_info_file`.
- `create_slurm_sub_sh(self, jobname, mem_per_core_mb, log_dir, run_script="run_exe_analysis.sh", job_dir="job_scripts", db_info_file=None, account_name=None, n_cores_per_job=10, n_xtr_cmds=0, n_jobs=10, job_time_limit="2-23:59", module_load="module load parallel singularity", partition="compute", use_array=False, max_concurrent=None, mem_total_mb=None, qos=None, constraint=None, gres=None, extra_sbatch_args=None)` — Writes `jobcmds.sh`, `.sbatch` file(s) (`job_array.sbatch` when `use_array=True`), and executable `run_script`.

## `pbprocesstools.pbpt_process.PBPTProcessToolsBase`

Inherited by both `PBPTQProcessTool` and `PBPTGenQProcessToolCmds`:
- `uid_generator(size=6) -> str`
- `generate_readable_timestamp_str() -> str` (`YYYYMMDD_HHMMSS`)
- `find_file(dir_path, file_search) -> Optional[str]` (accepts `str` or iterable of directories; returns single match or `None`)
- `find_first_file(dir_path, file_search, rtn_except=True) -> Optional[str]`
- `get_file_basename(file_path, check_valid=False, n_comps=0, rm_n_exts=1) -> str` (`rm_n_exts=0` strips all extensions)
- `create_dir(dir_path, use_abs_path=True, add_uid=False) -> tuple[str, bool]`
- `remove_dir(dir_path)`
- `has_files(dir_path: str, recursive: bool = False) -> bool` (`@staticmethod`)
- `check_files(files_dict) -> tuple[bool, dict]`

`check_files(files_dict)` specification values:
- `"file"` — path exists
- `"filesize"` — regular file with `size > 0`
- `"gdal_image"` or `{"type": "gdal_image", "n_bands": 0, "chk_proj": False, "epsg_code": 0, "read_img": False, "smpl_n_pxls": 10, "calc_chk_sum": False, "max_file_size": None, "timeout": 4}`
- `"gdal_vector"` or `{"type": "gdal_vector", "chk_proj": False, "epsg_code": 0, "max_file_size": None, "timeout": 4}`
- `"hdf5"` or `{"type": "hdf5", "timeout": 4}`

## `pbprocesstools.pbpt_db_clean` & `pbpt_clean_db.py`

Programmatic API: `PBPTDatabaseCleaner(db_conn_file=None, db_conn_str=None)`
- `list_queue_tables(schema=None, all_schemas=False, pattern=None, tables=None) -> list[dict]`
- `select_tables_for_cleanup(...) -> list[dict]` (filters: `completed`, `empty`, `finished`, `older_than_days`, `all_tables`, `tables`, `pattern`)
- `drop_tables(table_infos, force=False, dry_run=False, drop_empty_schemas=False, vacuum=False) -> dict`
- `vacuum_analyze(dry_run=False) -> bool`

Table classification states: `EMPTY`, `ACTIVE` (pending or running > 0), `FINISHED_WITH_ERRORS`, `COMPLETED`.

CLI flags (`pbpt_clean_db.py` / `pbpt_clean_db`):
- Connection & scope: `-d/--dbfile`, `--db-conn-str`, `--schema`, `--all-schemas`
- Actions: `-l/--list` (default), `--json`, `--drop`, `-i/--interactive`, `--vacuum`
- Selection: `-t/--tables`, `--pattern`, `--completed`, `--empty`, `--finished`, `--older-than DAYS`, `--all`
- Safety & extras: `--force` (required to drop `ACTIVE`), `--drop-empty-schemas`, `--dry-run`, `-y/--yes`
